# LANlord

> all your LAN are belong to you

## supported platforms

the gateway is the machine lanlord manages; the client is where you run `lanlord`.

| role | os | arch | status |
|---|---|---|---|
| gateway | arch linux (rolling) | x86_64 | first target |
| client | macos | arm64, x86_64 | supported |
| client | arch linux, manjaro | x86_64 | supported |
| client | windows 10+ | x86_64 | planned; needs the openssh client |

other distros and architectures come after arch. the gateway targets arch's rolling release, so there is no fixed version to pin.
